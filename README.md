# Selenium Anti-Detection Starter Kit (Demo)

This repository contains a safe, minimal demo of how to **structure** a Selenium automation project with anti-detection patterns, without targeting any specific platform.

This is a **demo only**:
- no production logic
- no site-specific automation
- no evasion guarantees

The goal is to showcase:
- project structure
- driver setup patterns
- basic stealth configuration
- a simple example login flow

---

## 📚 Contents

### demo/
- `driver_setup.py` — central place to create a configured WebDriver instance
- `stealth_config.py` — placeholder functions for applying stealth-like settings
- `example_login_flow.py` — non-functional demo of how a login flow *would* be structured

### screenshots/
- `browser_profile.png` — placeholder screenshot of a browser profile or generic browser window

---

## 🎯 Purpose

This repo exists to demonstrate:
- how to centralize Selenium setup
- how to apply configuration in one place
- how to keep flows modular and testable
- how to separate concerns (setup vs. behavior)

It is designed to attract:
- automation clients
- scraping/QA work
- backend + browser orchestration consulting
